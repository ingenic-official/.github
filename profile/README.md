## 贡献指南 / Contributing

我们欢迎社区提交 Issue 与 Pull Request。提交前请阅读目标仓库的 `CONTRIBUTING.md`。参与本项目即表示同意遵守我们的行为准则。

We welcome issues and pull requests from the community. Please read the `CONTRIBUTING.md` in the target repository before contributing. By participating, you agree to abide by our Code of Conduct.

## 开源许可 / Licensing

各仓库以其自身的 `LICENSE` 文件为准。部分硬件手册、SDK 与预编译固件可能适用单独的许可条款，详见对应仓库的说明。

Each repository is governed by its own `LICENSE` file. Certain hardware manuals, SDKs and prebuilt firmware may be subject to separate license terms; see the respective repository for details.

## 安全披露 / Security

如发现安全漏洞，请勿提交公开 Issue。请发送邮件至 github_official@ingenic.com，我们会在 3 个工作日内回复。

If you discover a security vulnerability, please do not open a public issue. Email github_official@ingenic.com instead, and we will respond within 3 business days.
